Everything needed to run fish_ctrl_02 and fish_Onirifalx on a machine with
nothing else installed.

1. Install Rust: https://rustup.rs
2. From this folder:
   ```
   cargo run --release --bin fish_ctrl_02
   ```
   or
   ```
   cargo run --release --bin fish_Onirifalx
   ```

That's it — no other files, folders, or setup steps needed.
